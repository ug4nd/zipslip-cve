# zipslip.py

*[English version](README.md)*

Небольшая CLI-утилита для сборки ZIP-архивов, в которых **имя записи
(arcname)** можно задать независимо от реального имени файла на диске.

Это тонкая обёртка вокруг штатных, документированных возможностей
стандартного модуля Python
[`zipfile.ZipFile.write(filename, arcname=...)`](https://docs.python.org/3/library/zipfile.html#zipfile.ZipFile.write)
и `writestr()`, которые уже поддерживают такое поведение — скрипт
просто предоставляет к ним удобный интерфейс на `argparse`, вместо
того чтобы каждый раз писать несколько строк на Python самостоятельно.

## Зачем это нужно

["Zip Slip"](https://security.snyk.io/research/zip-slip-vulnerability) —
известный класс уязвимостей: серверный код распаковывает ZIP-архив и
записывает каждую запись на диск, используя имя записи «как есть»
(например `open(os.path.join(dest_dir, entry.filename), "wb")`), без
проверки того, что итоговый путь остаётся внутри нужной выходной
директории. Вредоносный архив с именем записи вида
`../../../etc/passwd` или с абсолютным путём может заставить
распаковщик записать файл за пределами целевой директории.

Этот репозиторий — учебный/портфолио-проект, сделанный в процессе
прохождения задания по Zip Slip на лабораторной/CTF-платформе.
`zipslip.py` позволяет быстро собирать тестовые архивы с нужными
(в том числе «path-traversal» или абсолютными) именами записей, чтобы
проверить собственный код распаковки и убедиться, что он корректно
отклоняет/нормализует небезопасные записи (например, сверяя
`os.path.realpath()` каждого итогового пути с целевой директорией
перед записью).

**Эта утилита только собирает ZIP-файлы средствами стандартной
библиотеки. Она не распаковывает архивы и сама по себе ничего не
эксплуатирует** — она предназначена для подготовки тестовых входных
данных для вашего собственного кода распаковки/санитизации.

## Использование

```
python zipslip.py -o OUTPUT.zip [--list] [--force|-f] \
    add SOURCE_FILE --as ARCNAME \
    [add SOURCE_FILE --as ARCNAME ...] \
    [add-text "literal text" --as ARCNAME ...]
```

- `-o / --output` — путь к создаваемому ZIP-архиву (обязательный).
- `add <file> --as <arcname>` — добавить существующий файл с диска,
  сохранив его под указанным именем записи.
- `add-text "<text>" --as <arcname>` — добавить произвольную строку как
  содержимое файла, сохранив её под указанным именем записи.
- `--list` — после записи вывести `namelist()` архива.
- `-f / --force` — перезаписать выходной файл, если он уже существует.

В одном вызове можно комбинировать несколько `add` / `add-text`; они
записываются в том порядке, в котором указаны.

### Пример

```
python zipslip.py -o demo.zip --list \
  add payload.txt --as "../../tmp/evil.txt" \
  add-text "hello" --as "notes/readme.txt"
```

```
Wrote demo.zip with 2 entries.
Archive namelist():
  '../../tmp/evil.txt'
  'notes/readme.txt'
```

## Кому это нужно

Всем, кто изучает безопасность распаковки архивов (например,
проходит лабораторное задание по Zip Slip) и хочет быстро генерировать
ZIP-архивы с конкретными, заданными именами записей — без ручного
написания шаблонного кода на `zipfile` каждый раз — чтобы проверить
собственный безопасный код распаковки.
